# Rubies Organic

This project is a single-page storefront and contact portal for Rubies Organic.

## Quick start
- Start the backend: npm start
- Run the build check: npm run build
- Test the order endpoint: npm run test:order
- Deploy to Netlify: netlify deploy --prod

## Project structure
- index.html: main website pages
- contact.js: opens a prefilled SMS to the quick support number from the contact form
- javascript.js: shop, cart, checkout, and contact logic
- shop.js: product and shopping interactions
- nav.js: mobile navigation
- logistics.js: registration flow
- rubies-backend/: Express backend and worker

See PROJECT_GUIDE.md for a fuller overview.
